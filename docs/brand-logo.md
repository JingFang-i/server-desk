# ServerDesk 应用图标（品牌资产）

> 资产全部由 `apps/desktop/scripts/gen-icon.py` 生成，不依赖任何设计软件；
> 改颜色/几何只需改脚本里的常量再跑一次，所有尺寸与格式一次到位。

## 概念

产品做的事是「让 AI 在你自己的服务器上执行命令」，所以主形取**终端行首提示符 `>`**
加一道**青色光标**。一个剪影、两层信息：终端（AI 执行）+ 光标（等待输入 / 正在运行）。

不做装饰性底纹。第一版试过「三条机架槽位」的极淡底纹，在 16–128px 会被读成一块文字，
属于降低品质的噪声，已删除——图标在 16px 能不能一眼认出，比在 512px 有多少细节更重要。

## 构成

| 元素 | 规格 |
|---|---|
| 底板 | 超椭圆（`\|x\|^n + \|y\|^n = 1`，n = 5），四边内缩 8.5%，接近 macOS Big Sur 的连续曲率圆角 |
| 底色 | 45° 线性渐变 `#1B2545 → #090D1A`（深墨蓝，不是纯黑，避免在深色桌面上"糊掉"） |
| 材质 | 顶部 30% 白色柔和高光（峰值 10%）+ 底部 16% 黑色柔化（峰值 9%），做出实体厚度，不用描边 |
| 主形 | 提示符 `>`，笔画 9%（相对画布），圆头圆角折线，白色 95% |
| 强调 | 光标条 `#22D3EE`，厚度 7.5%（略细于笔画），圆角 3.75% |
| 居中 | 主形包围盒中心精确落在画布 (0.5, 0.496)——按包围盒算，不按目测 |

## 工艺

- 4096² 超采样后 LANCZOS 降采样，每个尺寸边缘都干净（16px 也不出现毛边）
- 遮罩用 numpy 直接算超椭圆不等式，逐像素判定 + 超采样抗锯齿
- 同一份主图导出所有尺寸与格式，避免各尺寸观感漂移

## 导出物

`apps/desktop/src-tauri/icons/`：

- `icon.icns`（16→1024，macOS 打包与 Dock）
- `icon.ico`（7 个尺寸，Windows）
- `32x32.png` `64x64.png` `128x128.png` `128x128@2x.png` `icon.png`(512)
  （Tauri `bundle.icon` 与 `default_window_icon`——托盘图标也取自这里）
- `Square*Logo.png` / `StoreLogo.png`（Windows 商店尺寸，跟随主图）

`apps/desktop/src/assets/logo.png`（256px）：侧栏品牌位使用，与 App 图标同源。

## 重新生成

```bash
python3 apps/desktop/scripts/gen-icon.py   # 需要 Pillow + numpy；macOS 上用 iconutil 打包 icns
cd apps/desktop && pnpm tauri build        # 图标在构建时嵌入，需重新打包才生效
```

## 小尺寸自检

生成后把 16/32/64/128 放大到 256 并排看，确认：

- 16px 仍能读出「> + 光标」两个形，不糊成一团
- 底板缩到 16px 时渐变不过曝、不消失
- 圆角在 16px 不出现锯齿台阶
