# 实验性敏感引用（Secret Indirection）退役与迁移

实验性的敏感值登记、句柄、有效期设置和后台清扫已移除。新安装无需迁移。旧数据库保留已有的加密登记记录，桌面应用已移除对应的查询和使用入口。用于 SSH 登录的服务器密码和私钥继续由原有保险库管理。

## 哪些资产会关闭 AI 操作

首次打开含旧引用表的数据库时，ServerDesk 会根据记录调整资产的“允许 AI 操作”开关。

| 旧库中的记录 | 首次升级时的处理 |
| --- | --- |
| 记录标记有远端副本，或旧表缺少副本标记 | 关闭对应资产的 AI 操作 |
| 该资产的记录全部明确标记仅在本地保存，或没有该资产的记录 | 保留原有开关状态 |

## 使用过远端登记时如何处理

1. 确认当时实际使用的 SSH 主机及登录用户。若资产改过地址或换过账号，按原主机和原身份核对。
2. 在原主机上检查 `/run/serverdesk-secrets/`，确认文件归属后清理实验功能留下的凭据副本。升级过程不会连接远端执行删除。已删除的旧登记无法用于定位副本，即使升级没有关闭开关，使用过远端登记的主机也应核对。
3. 核对完成后，需要继续通过 MCP 管理该资产的用户，可在资产设置中重新开启“允许 AI 操作”。该迁移只执行一次。
