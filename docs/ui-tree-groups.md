# 服务器列表分组树形展示 验收

> 纯前端改动（ServersView.vue），无后端/安全管线变化。

## 行为

- 列表按「分组」树形展示：分组行为可折叠的 `📁 分组名（N 台）`，子行为该组服务器
- 无分组（group 为空）的服务器归入 **默认分组**，固定排在所有分组之后
- 分组按名称排序；默认**全部展开**（受控 keys，异步数据加载后依然生效），可手动折叠
- 分组行仅显示 📁 名称与台数，其余列显示 —；子行保留全部列与操作（连接/命令/下拉/详情）
- 工具栏原「分组筛选」下拉移除（树形本身即分组视图）；搜索保留，命中服务器的分组自动聚拢
- 新增/编辑表单的分组选择不变（可选现有分组或输入新分组）

## 验证

- `pnpm build`（vue-tsc + vite）通过；`scripts/check_vue_imports.py` 通过
- 模拟 IPC 浏览器实测：分组行 📁 渲染与计数正确、子行归属正确、默认分组垫底、受控展开生效、子行 3 个操作按钮齐全（2 台 × 3 = 6 按钮）、零 JS 报错
