# R11 验收：ServerDesk 桌面工作台

## 范围

- 工作台导航、快捷搜索、服务器分组与连接反馈。
- AI 活动轨道、审批时间与结果反馈、审计详情侧栏。
- 设置目录、备份恢复说明和保险库锁屏。

交互与样式见 [UX-CONTRACT.md](UX-CONTRACT.md) 和 [DESIGN.md](DESIGN.md)。

## 验收步骤

| 场景 | 操作 | 预期 |
| --- | --- | --- |
| 窄窗口 | 将主窗口调整为 900 × 600 | 侧栏显示图标，连接、搜索和待审批入口可以使用 |
| 键盘定位 | 按 Cmd/Ctrl + K，输入服务器名称，按 Enter | 回到服务器页，展开目标分组并显示资产详情 |
| 状态保留 | 设置连接失败筛选，切去审批再返回 | 保留筛选和已选服务器 |
| SSH 状态 | 使用测试机触发失败，重试并验证取消和成功 | 显示失败原因、取消入口和成功后的命令及文件传输入口 |
| 审批和审计 | 提交测试请求，验证最早到期项、过期、拒绝、审批错误与审计详情 | 不重复提交，审计详情关闭后回到触发按钮 |
| 备份 | 选择测试备份，选择覆盖，打开确认后取消 | 清楚标明影响，取消时未调用恢复 |
| 锁定与动效 | 开启系统减少动态效果，锁定再解锁 | 动效随系统设置变化，锁定时快捷搜索不可用 |

## 本地检查

在仓库根目录运行 `cargo check --workspace` 和 `python3 apps/desktop/scripts/check_vue_imports.py`，再执行 `pnpm --dir apps/desktop build`。使用离线测试资产或模拟 Tauri 响应验证界面。测试原生通知、真实 SSH 与跨平台窗口时，使用各平台的隔离测试环境。
