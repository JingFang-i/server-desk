## P1

### 1. 跨机器恢复报告成功，但目标保险库无法解密凭据

手动备份用备份口令保护外层文件，内部仍保存由源保险库数据密钥加密的凭据。恢复时原样写入凭据密文。两个独立初始化的保险库即使使用相同主密码，也会生成不同的数据密钥。覆盖恢复会替换原有资产，并报告导入成功，之后读取导入凭据时才报解密错误。

已用两个临时保险库复现。修复时应在写库前验证并转换全部凭据，再用事务提交。需要为现有备份格式明确兼容或迁移方式。

[backup.rs 第 172–185 行](../apps/desktop/src-tauri/src/backup.rs#L172-L185)

### 2. 白名单和只读模式按文本判断整段 Shell 命令

白名单通过子串匹配判断整段命令，只读模式依赖已知写操作的正则。通过检查的原始命令随后交给远端 Shell，复合命令中的其他操作可能未经授权执行。

建议将受限模式收敛到明确允许的只读操作和参数，并用远端账号权限约束实际写入。

[guard.rs 第 369–399 行](../apps/desktop/src-tauri/src/guard.rs#L369-L399)

### 3. 文件保护校验的是输入路径文本

敏感文件和禁写位置按调用方提交的路径文本判断，SFTP 随后按远端文件系统解析路径。符号链接等别名可能使实际打开的对象落到受保护位置。

建议把保护落实到实际打开的对象，并用远端账号权限或受控目录限制可达文件范围。

[guard.rs 第 402–425 行](../apps/desktop/src-tauri/src/guard.rs#L402-L425) · [ssh.rs 第 335–345 行](../apps/desktop/src-tauri/src/ssh.rs#L335-L345)

### 4. 观测工具跳过严格分组审批

设置页承诺严格分组的只读命令也需批准。目录、日志、服务和端口观测共用的 `observe_exec` 直接执行 SSH，缺少严格分组检查。

建议让观测工具复用命令审批流程，在执行前落实分组策略。

[observe.rs 第 63–79 行](../apps/desktop/src-tauri/src/observe.rs#L63-L79) · [SettingsView.vue 第 238–242 行](../apps/desktop/src/views/SettingsView.vue#L238-L242)

### 5. 修改服务器配置后仍会复用旧 SSH 会话

修改主机、端口、用户名或凭据只更新数据库。SSH 和 SFTP 按服务器 ID 复用现有连接，后续操作可能发往旧主机，或继续以旧身份执行。

建议将会话绑定到配置版本。配置更新时淘汰旧会话，并防止正在使用的旧会话重新入池。

[commands.rs 第 235–242 行](../apps/desktop/src-tauri/src/commands.rs#L235-L242) · [ssh.rs 第 227–247 行](../apps/desktop/src-tauri/src/ssh.rs#L227-L247)

### 6. 写前备份把远程文件明文保存在本地

自动写前备份将远程原文件的字节直接写入 `.bak`。普通配置文件也可能包含密码或令牌，这些内容在保险库锁定后依然以明文存在。

建议用保险库密钥加密备份内容，并提供已有明文备份的迁移方式。

[fbackups.rs 第 49–58 行](../apps/desktop/src-tauri/src/fbackups.rs#L49-L58)

## P2

### 7. SSH 和 SFTP 的大小上限在接收后才生效

SFTP 将完整文件读入内存后才判断是否超限。SSH 命令输出也先累积再截断，资源消耗可能远超设定值。SSH 还按固定字节位置截断字符串，已用含中文的本地样本复现 UTF-8 边界 panic。

建议在接收阶段限制缓冲区，并在有效的 UTF-8 字符边界截断。

[ssh.rs 第 346–362 行](../apps/desktop/src-tauri/src/ssh.rs#L346-L362) · [ssh.rs 第 483–513 行](../apps/desktop/src-tauri/src/ssh.rs#L483-L513)

### 8. SSH 输出读取超时仍返回成功结果

读取输出的超时结果被丢弃，函数仍返回 `Ok`，批量执行也会把这一项标记为成功。调用方无法区分远端执行完成和仅收到部分输出。

建议将超时或执行结果未确认作为独立状态返回，并由 MCP 和界面准确展示。

[ssh.rs 第 483–513 行](../apps/desktop/src-tauri/src/ssh.rs#L483-L513) · [ops.rs 第 739–749 行](../apps/desktop/src-tauri/src/ops.rs#L739-L749)

### 9. 追加文件会覆盖审批期间的新内容

`append_file` 先读取文件，再等待人工审批，最后将读取时的内容和新增内容整文件写回。服务或其他操作者在审批期间写入的数据可能被覆盖。

建议在审批后使用远端原生追加语义。若业务必须整文件重写，应在写入前检查版本并报告冲突。

[ops.rs 第 548–566 行](../apps/desktop/src-tauri/src/ops.rs#L548-L566)

### 10. 批量执行的 5 路并发限制未生效

批量任务复制了信号量，但执行前没有申请许可，同批最多 20 台服务器的任务可以同时进入执行流程。

建议每个任务在发起远程操作前取得许可，并持有至该台服务器的操作结束。

[ops.rs 第 704–711 行](../apps/desktop/src-tauri/src/ops.rs#L704-L711)

### 11. 并发 MCP 请求会串写审计会话

会话 ID 存放在进程级共享变量里。一个请求等待 SSH 或审批时，另一个客户端的请求可以覆盖这个值，导致完成记录记到其他会话。验收文档已记录可能出现归因交错。

建议将会话 ID 作为请求上下文显式传给审计与批量子任务。

[ops.rs 第 65–88 行](../apps/desktop/src-tauri/src/ops.rs#L65-L88) · [r1-r5-acceptance.md 第 50–53 行](r1-r5-acceptance.md#L50-L53)

### 12. 分组树合并同名分组，并重置用户折叠状态

已用当前 Vue 响应式逻辑复现。真实分组命名为「默认分组」后，会与未分组的服务器合并显示。搜索或刷新导致表格数据重算时，已有分组会被统一展开。

建议为未分组项使用独立内部键，并在数据更新时保留已有分组的折叠状态。

[ServersView.vue 第 115–158 行](../apps/desktop/src/views/ServersView.vue#L115-L158)
